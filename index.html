What this map can and cannot show: Older events appear only if they were seen and written down, so the further back you look, the more events are missing, and early tolls are estimates. Symbols show where each event is catalogued, not the full area affected. "Missing" counts are converted from text to numbers; blank values are treated as not recorded. Events with no year are shown only when the slider covers the full range. Use the map to explore patterns, not to calculate risk.
Sources: Earthquake, tsunami and volcanic event layers hosted on ArcGIS (see LAYERS in the code); basemap: Esri World Basemap v2 vector tiles. Projection: Web Mercator, which enlarges areas near the poles.
